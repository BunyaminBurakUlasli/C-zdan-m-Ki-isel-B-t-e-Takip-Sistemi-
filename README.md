Proje Adı: Cüzdanım (Kişisel Bütçe Takip Sistemi)
• Projenin Kısa Özeti: Cüzdanım, bireylerin günlük gelir ve giderlerini dijital ortamda
kolayca kayıt altına almalarını sağlayan web tabanlı bir kişisel bütçe takip
uygulamasıdır. Kullanıcılar sisteme miktar, kategori, açıklama ve tarih bilgileriyle
işlemler ekleyebilir, geçmiş kayıtlarını düzenleyebilir veya silebilirler. Uygulama, toplam
gelir ve gideri otomatik hesaplayarak güncel bakiyeyi ekranda gösterir ve harcamaların
kategori dağılımını grafiksel olarak sunarız
